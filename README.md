# About this Project

I created an online chatbot using python code. This chatbot is capable of responding to certain prompts from the user and can also generate multiple cat images when you message "cat". 
- If you say "안녕", which is Hi in Korean, it'll respond with "안녕, 만나서 반가워."
- If you say "기분이 어때", it will respond with a random message on how its feeling.
- If you say a prompt that is not in the code, it will respond with "아직 무슨 말인지 모르겠어."
- Lastly, if you say "cat", it will generate an image of a random cat. If you refresh the page and try again, it will generate a different image.
